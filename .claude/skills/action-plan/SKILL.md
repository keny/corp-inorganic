# アクションプランの作成・更新

strategy-planner エージェントで月次アクションプランを生成し、要点を報告する。

## 手順

1. **鮮度確認**: `research/market/` の最新スキャンが 2 週間以上古い場合、先に `/market-scan` の実行を提案する(ユーザーが急ぐ場合は古いデータのまま進めてよいが、プランにその旨を明記させる)。
2. **strategy-planner エージェントを起動**(subagent_type: strategy-planner)。今日の日付と、特に検討してほしい論点(ユーザー指定があれば)を渡す。
3. 完了後、ユーザーに報告する:
   - 状況サマリーと優先案件トップ 3
   - 今週・今月のアクション(担当・期限)
   - **経営判断が必要な事項**(最重要。埋もれさせない)
   - 保存先パス
4. プラン内の next_action が pipeline.yaml と食い違う場合は、deal-desk エージェントで pipeline 側の next_action を同期する。

## 注意

- プランの中身の妥当性に違和感があれば、strategy-planner に差し戻して修正させてからユーザーに出す。
- 経営判断事項はエージェントが勝手に「決定」しない。推奨案と判断期限を付けてユーザーに提示するに留める。
