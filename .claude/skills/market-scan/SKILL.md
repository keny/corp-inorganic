# 市場スキャンの実行

market-scout エージェントで市場スキャンを実行し、結果をユーザーに報告する。

## 手順

1. **market-scout エージェントを起動する**(Agent ツール、subagent_type: market-scout)。プロンプトに含めること:
   - 今日の日付
   - テーマ指定(引数)があればそのテーマに絞る旨。なければ全般スキャン(直近の未スキャン期間が対象。`research/market/` の最新レポートの日付以降)
   - `templates/market-scan.md` の構成に従い `research/market/` に保存すること
2. 完了後、レポートを確認し、ユーザーに以下を報告する:
   - TL;DR とレポートの保存先
   - **新規候補の提案があった場合**: 一覧を示し、有望なものを pipeline に `00_sourcing` として追加するか提案する(追加の実行は deal-desk エージェント経由)
   - **既存案件に影響するニュースがあった場合**: 該当案件と推奨対応を明示する
3. ユーザーが候補追加や案件更新に同意したら deal-desk エージェントで反映する。

## 注意

- スキャンの実体は market-scout に委任する。メインセッションで直接 Web 検索を始めない。
- 同日 2 回目以降の実行はファイル名にテーマや連番を付けて上書きを避ける。
