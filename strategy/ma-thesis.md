# SORACOM インオーガニック成長テーゼ（M&A・出資・提携）

> ステータス: **初期ドラフト（作業仮説）** — 経営会議での議論・承認前。エージェントチームの初期設定として作成したものであり、内容はチームで随時更新すること。
> 最終更新: 2026-07-06

## 1. 目的 — なぜインオーガニックか

SORACOM はグローバル IoT プラットフォーム（コネクティビティ〜アプリケーションレイヤー）を自社開発中心で拡張してきた。インオーガニック手段（買収・出資・提携）は以下の場合にのみ使う:

1. **時間を買う** — 自社開発では市場投入が 18 か月以上遅れる能力・資産
2. **獲得困難な資産を買う** — 顧客基盤、チャネル、周波数・規制上の地位、希少な技術チーム
3. **業界再編に対応する** — 競合の統合により当社の相対ポジションが毀損されるのを防ぐ

「安いから買う」「話が来たから検討する」は理由にならない。すべての案件はこの 3 分類のどれに該当するかを明示すること。

## 2. 戦略ピラー（候補領域）

各案件は必ずいずれかのピラーに紐付ける。ピラーに紐付かない案件は原則見送り。

### P1: コネクティビティの深化
- 対象: eSIM/iSIM オーケストレーション（SGP.32 対応）、衛星 NTN、プライベート 5G / ローカル 5G、LPWA
- 仮説: 接続手段の多様化が進むほど「単一プラットフォームで全接続を管理できる」価値が上がる。SORACOM Air の接続レイヤーの技術的な堀を広げる。

### P2: デバイス・エッジレイヤー
- 対象: デバイス管理・プロビジョニング、エッジ AI ランタイム、IoT デバイスセキュリティ
- 仮説: 接続の上下（デバイス側・エッジ側）を押さえることで解約障壁と ARPU を高める。

### P3: データ・アプリケーションレイヤー
- 対象: IoT データ分析・可視化、業界特化アプリケーション（Harvest / Lagoon / Flux / Query の延長線）
- 仮説: 接続データの活用レイヤーは粗利率が高く、AI との親和性も高い。ただし自社開発（Flux 等）との競合に注意し、Build vs Buy を厳格に判断する。

### P4: 地理的拡大・顧客基盤
- 対象: 欧米・アジアの IoT MVNO / コネクティビティ事業者、地域チャネル・SIer（同業ロールアップ含む）
- 仮説: グローバル顧客の獲得コストは買収の方が安い場合がある。回線収入と一緒に顧客関係を買う。

### P5: ケイパビリティ獲得（acqui-hire）
- 対象: 特定技術領域（例: 通信コア、AI、セキュリティ）の少人数精鋭チーム
- 仮説: 採用市場で確保困難な人材をチームごと獲得する。小規模・低リスクだが PMI でのリテンション設計が全て。

## 4. キルクライテリア（即時見送り・撤退条件）

以下のいずれかに該当したら、サンクコストに関わらず見送り・撤退を原則とする:

1. 売上の 50% 超が単一顧客に依存し、解消の見込みがない
2. キーパーソンのリテンションが構造的に困難（既に離脱意向、競業避止が効かない等）
3. 技術デューデリジェンスで根本的な負債が判明（当社基準でのセキュリティ・スケーラビリティ要件を満たせない）
4. 法務・規制・コンプライアンス上の重大懸念（制裁・輸出管理・データ保護違反等）
5. 文化的不適合の明確な兆候（バリュー・顧客への向き合い方の相違）
6. Build / Partner で 12 か月以内に同等の結果が得られると判明

## 5. Build / Buy / Partner 判断枠組み

すべての案件で以下を比較すること:

- **Build**: 自社開発した場合の期間・コスト・成功確率
- **Buy**: 買収価格 + 統合コスト + リテンションリスク
- **Partner**: 提携・再販で得られる価値と、依存リスク

「Buy が最善」と言えない案件は、出資（将来の買収オプション）または提携に切り替える。
