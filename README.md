# corp-inorganic — SORACOM M&A 戦略エージェントチーム

SORACOM のインオーガニック成長(M&A・マイノリティ出資・事業提携)を支援する Claude Code エージェントチームのワークスペース。市場リサーチ、候補企業の個別調査、案件パイプラインの進捗管理、アクションプラン策定を継続的に回す。

> ⚠️ **機密**: 本リポジトリは M&A 検討情報を含みうる(インサイダー情報になりうる)。アクセス権限は必要最小限に保ち、内容を外部に共有しないこと。
> ⚠️ **免責**: エージェントの分析は公開情報に基づく参考情報であり、投資判断・法務判断ではない。重要な意思決定は経営会議・外部アドバイザーの確認を経ること。

## クイックスタート

Claude Code でこのリポジトリを開き:

```
/weekly-review        # 週次フルサイクル(初回実行はこれ)
/market-scan          # 市場スキャンのみ
/deep-dive Acme Corp  # 特定企業の深掘り
/pipeline status      # 案件状況の確認
/action-plan          # アクションプラン更新
```

自由入力でも動く(例: 「最近の eSIM 関連の動きを調べて」「Acme 社をパイプラインに追加して」)。Claude が適切なエージェントに委任する。

## エージェントチーム構成

| エージェント | 役割 | 例えるなら |
|---|---|---|
| **market-scout** | 市場・競合・ディール動向の継続調査、候補発掘 | リサーチアナリスト |
| **target-analyst** | 候補企業 1 社の詳細調査・スコアリング | コーポレートデベロップメント担当 |
| **devils-advocate** | 推進論への反証、リスク洗い出し、キルクライテリア照合 | 社外取締役の厳しい人 |
| **deal-desk** | パイプライン(pipeline.yaml)の管理と進捗監視 | PMO |
| **strategy-planner** | 全情報の統合と優先順位付きアクションプラン策定 | 戦略参謀 |

## リポジトリ構成

```
.claude/agents/      エージェント定義(5名)
.claude/skills/      スラッシュコマンド(5本)
strategy/            M&A戦略テーゼ・評価基準 ← まずこれを経営で合意する
pipeline/            案件パイプライン(YAML) ← 単一の情報源
research/market/     市場スキャンレポート
research/targets/    企業別プロファイル・反証メモ
plans/               月次アクションプラン
templates/           ドキュメントテンプレート
```

## 運用サイクル

1. **週次**: `/weekly-review` — 市場スキャン → パイプライン健全性チェック → 停滞案件の更新 → アクションプラン更新 → 経営向けサマリー。定期実行ルーティン(Claude Code のトリガー)で自動化可能。自動実行時は draft PR として結果が届く。
2. **随時**: 候補が浮上したら `/deep-dive <会社名>`。会議で動きがあったら `/pipeline update <案件ID>`。
3. **月次**: `/action-plan` で月次プランを確定。`strategy/ma-thesis.md` の前提を見直す。

## 最初にやること(セットアップ後)

1. `strategy/ma-thesis.md` と `strategy/evaluation-criteria.md` はドラフト。経営メンバーでレビューし、ガードレール(案件規模等)を確定させる。
2. `pipeline/pipeline.yaml` のサンプル案件(SAMPLE-*)を削除し、既存の検討案件を登録する(`/pipeline add`)。既存資料(スプレッドシート等)からの一括取り込みも Claude に依頼できる。
3. 週次ルーティンの有効化(任意): Claude Code のセッションで「週次レビューのルーティンを設定して」と依頼するか、claude.ai の設定からスケジュールを作成する。
